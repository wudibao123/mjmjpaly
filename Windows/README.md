# MJMJ · 液态玻璃音乐播放器

基于 Electron + WebGL 的网易云音乐桌面播放器。由「液态玻璃灵动岛」网页播放器改造而来：保留原版 WebGL 液态玻璃、歌词漂移、KTV 胶囊追光等视觉核心，新增网易云账号体系（扫码 / Cookie 登录、歌单同步）、跟随音乐节奏流动的 CSS 背景、背景选择面板（默认原图 / CSS 节奏流 / 自选图片 / 透出桌面）。

## 功能特性

- **网易云登录**：扫码登录（App 扫一扫）+ 粘贴 Cookie 登录，登录态缓存本地（`userData/auth.json`）
- **歌单同步**：登录后自动拉取「我的歌单」，歌单内歌曲支持**长按拖拽排序**（拉上/拉下调整显示顺序）
- **收藏同步**：HUD「收藏」按钮弹出「我喜欢的音乐」，同步网易云账号收藏，即点即播
- **独立搜索页**：HUD「搜索」按钮打开独立搜索页面，搜歌名/歌手/专辑，点击结果直接播放
- **播放进度条**：常驻显示在底部导航栏上方，支持点击与拖拽跳转进度
- **液态玻璃**：原版 WebGL shader 迁移 —— 凹陷深度、模糊、折射、边缘色差、节奏推拉，参数面板可调可保存
- **KTV 胶囊追光**：歌词胶囊随唱段高亮滚动
- **歌词玩法**：歌词行随机漂移、可拖拽、点击跳转播放进度
- **节奏 CSS 背景**：WebAudio 实时分析（低频/中频/高频/能量）驱动 CSS 变量，背景图随节奏流动、色相偏移
- **背景四模式**：
  - 默认原图（原 HTML 内嵌 base64 背景图）
  - CSS 节奏流（极光渐变随音乐流动）
  - 自选图片（文件选择 / 直接拖入窗口）
  - 透出桌面（透明窗口，玻璃直接折射桌面内容）
- **窗口控制**：最小化 / 最大化还原（透明窗口全屏兼容，放大后可靠缩小）/ 关闭
- **灵动岛交互**：mini → hover → 展开三态，原版布局锚点（岛 top:16px、进度条 bottom:95px、HUD bottom:30px）
- **节奏推拉全局化**：低频推拉（`s-zoom`）同步驱动玻璃 shader 与整个背景层，整个画面随音乐推拉
- **搜索历史**：搜索页展示本地历史记录（最多 10 条），点击历史词直接重搜，可一键清空
- **音源容错**：取流多档位降级（exhigh→higher→standard→lossless→老接口兜底），后端代理带 Referer/Origin 防盗链头；音源失效（400/404）自动跳过下一首
- **扫码风控处理**：二维码轮询降频（6s）、3 分钟超时、过期/受限状态提示；被网易云风控拦截时自动切换到 Cookie 登录页并提示
- **纯线条 SVG 图标**：全界面无 emoji

## 目录结构

```
Windows/
├── main.js                  # Electron 主进程（无边框透明窗口 + IPC）
├── preload.js               # contextBridge 暴露 window.mjmj
├── package.json
├── server\
│   └── ncm-server.js        # Node 后端：网易云 API + 静态服务 + 音频代理 + 登录持久化
├── renderer\                # 渲染层（Android 端共用同一份）
│   ├── index.html           # 渲染层主页面（内联 SVG 图标）
│   ├── css\style.css
│   ├── js\
│   │   ├── ncm.js           # 网易云 API 客户端（二维码/Cookie/歌单/搜索/歌词）
│   │   ├── player.js        # 播放核心（队列/循环/歌词解析/WebAudio 分析）
│   │   ├── liquid.js        # WebGL 液态玻璃引擎 + 灵动岛 + 歌词 + KTV + CSS 节奏变量
│   │   └── app.js           # UI 装配（登录/歌单/背景面板/HUD/使用指南）
│   ├── vendor\              # 第三方库：three.js / paper / sonic
│   └── assets\default-bg.png
├── assets\icon\mjmj.ico     # 应用图标（MJ 笔画融合 + 圆形透明底）
└── scripts\                 # 构建与证书辅助脚本
```

## 运行

```bash
cd Windows
npm install        # 首次
npm start          # 启动应用（Electron）
```

> 注意：界面必须通过 `npm start` 启动（内部后端 `127.0.0.1:31999` 承载登录/搜索/歌单/音频代理）；用静态服务器直接打开 `renderer/index.html` 时 API 不可用。

## 打包

```bash
npm run dist       # electron-packager 打包 → dist\MJMJ-win32-x64\MJMJ.exe
npm run setup      # electron-builder 打包 NSIS 安装包 → release\MJMJ-Setup-<ver>.exe（向导式，可选安装位置）
```

> 可选：如需让自己的安装包不再触发 SmartScreen 提示，可自签名。运行 `scripts\make-cert.ps1` 生成自签名证书并按脚本提示把它导入本机「受信任的根证书颁发机构 / 受信任发布者」，然后设置环境变量 `MJMJ_CERT_PWD` 提供证书密码，构建时再通过 `-c.win.signtoolOptions.certificateFile` 等参数交给 electron-builder。仓库内不含任何证书文件与密码，未配置签名时构建产出的是未签名包。

## 使用指南

| 入口 | 说明 |
|---|---|
| HUD 右侧「登录」 | 扫码登录（网易云 App 扫一扫）或粘贴 Cookie |
| HUD「歌单」 | 打开面板：我的歌单 → 点进歌单看歌曲；**长按歌曲可拖动排序** |
| HUD「搜索」 | 独立搜索页：搜歌名/歌手/专辑，点击结果直接播放 |
| HUD「收藏」 | 同步网易云「我喜欢的音乐」，即点即播 |
| HUD「KTV」 | 开启/关闭胶囊追光歌词 |
| HUD「背景」 / 灵动岛·背景页 | 四背景模式 + 背景模糊 + 节奏开关 + 自选图片 |
| 进度条（底部导航栏上方） | 点击或拖拽跳转播放进度 |
| 灵动岛·玻璃参数页 | 凹陷/模糊/折射/色差/节奏推拉，调好后「保存当前配置」 |
| 播放中 | 点歌词行跳转、拖动歌词漂移、拖进度条、拖图片进窗口换背景 |

## 端口

- `127.0.0.1:31997` 主进程控制口（`/ping`、`POST /cli/play`、`GET /cli/audio`）
- `127.0.0.1:31998` NeteaseCloudMusicApi 内部服务（仅本机）
- `127.0.0.1:31999` 主服务（静态资源 + `/api/*` 反代 + `/proxy` 音频代理）
