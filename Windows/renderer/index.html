MJMJ 使用指南
登录同步歌单点 HUD 右侧「登录」→ 网易云 App 扫码，或粘贴 Cookie；登录态缓存本地，歌单自动同步。
搜索 / 歌单点「歌单」打开面板：顶部直接搜网易云音乐，登录后上方是我的歌单。
播放控制▶ 播放/暂停；两侧切歌；循环按钮切换 列表循环 / 单曲循环 / 随机播放。
KTV 胶囊追光点「KTV」开启胶囊追光字幕，歌词随唱段高亮滚动。
背景四模式点「背景」或展开灵动岛「背景」页：默认原图 / CSS 节奏流（随音乐流动）/ 自选图片 / 透出桌面。
液态玻璃调参展开灵动岛「玻璃参数」：凹陷、模糊、折射、色差、节奏推拉，调好点「保存当前配置」。
小技巧拖动玻璃换位置；点歌词行跳转、拖动歌词漂移；进度条可拖拽；本地图片可拖进窗口当背景。
